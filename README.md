# SubscribeIQ

## Subscription Management and Invoice Reconciliation System

SubscribeIQ is a web-based project designed to support subscription management, invoice tracking, payment records, and reconciliation.

## Project Overview

The project is organized into a frontend, a Java-based backend, and datasets containing subscription-related records.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Maven
- **Data:** CSV files
- **Version Control:** GitHub

## Project Structure

- `Backend/` — Backend source code and Maven configuration
- `frontend/` — User interface files
- `Dataset/` — Subscription, customer, invoice, and payment datasets

## Dataset Files

- `customers.csv`
- `invoice_items.csv`
- `invoices.csv`
- `payments.csv`
- `plans.csv`
- `reconciliation.csv`
- `subscriptions.csv`

## Project Objective

To organize subscription-related information and support the management of invoices, payments, and reconciliation records.
